How it works

Start it. See it. Fix it.

time-log is a simple loop. You start what you’re doing, your day fills in as a calendar, and you correct anything afterwards.

Step 1

Start

Type what you’re doing, or tap a recent activity. Whatever was running stops.

Step 2

See

Your day builds itself as a calendar. Time you forgot to track shows up as a gap.

Step 3

Fix

Wrong start time? Drag it into place. Undo any change.
